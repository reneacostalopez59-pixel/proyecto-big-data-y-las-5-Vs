# Dataset del Proyecto

Por cuestiones de peso y buenas prácticas, el dataset original utilizado para este análisis no se encuentra alojado en este repositorio.

## Instrucciones para obtener el dataset:

1. Ingresa a la página oficial del dataset en el siguiente enlace: `[https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page]`
2. Descarga el archivo de datos (debería llamarse `[yellow_tripdata_2026-07.parquet]`).
3. Coloca el archivo descargado directamente en esta carpeta (`data/`) sin cambiarle el nombre.
4. Al ejecutar el código, el programa buscará el archivo automáticamente en esta ruta.
